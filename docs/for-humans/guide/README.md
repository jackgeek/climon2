# User guide

How to install climon2, use the monitor and the other `c2` commands, and
configure them.

**Audience:** Users.

## Shared terms

You press the **escape prefix**, Ctrl+] by default, before a climon2 key,
so the keys climon2 uses never reach your command by accident. The
**climon2 home** is the folder where climon2 keeps session data, settings and
logs: `~/.climon2`, or the folder `CLIMON2_HOME` names.
