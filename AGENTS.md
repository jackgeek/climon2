# Agent instructions

## The factory builds climon2 — you build the factory

- Only change and invoke the factory (`factory/`, `features/` specs, `docs/`, repo tooling).
- **Never edit climon2 source code directly** (anything under `climon2/`). Not even to fix an obvious bug.
- When you find a climon2 bug, record the diagnosis and get the factory to fix it: add or adjust an acceptance test, give the implementer a better tool or prompt, or resume the run.
- If the factory can't fix it, fix the factory, not climon2.
