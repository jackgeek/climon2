THROWAWAY #56: reduced-profile derived restore/repaint qualification.
No production library, native rendering claim, wire protocol or full approval.

Question and answer
  Can unchanged Alacritty expose enough state for a small, derived byte-stream
  restore/repaint, deferring hidden normal content until actual exposure?
  YES for the bounded independently asserted cases below. Five new tests pass;
  32 runtime tests total, complete forwarding surface, formatting and Clippy.
  This is additional feasibility evidence, not every retained style/control
  state or production delivery guarantee. Human reaction is recorded on #56.

Mechanism
  Reuses the earlier #43 serializer approach, narrowed to cells/styles without
  hyperlinks, and the accepted #56 transition observer. restore reads only an
  immutable active View. No swap_alt, inactive-grid accessor, hidden normal
  preload or source-state mutation occurs.
  On an alternate attachment it paints only alternate content. On actual
  normal exposure, it paints normal/history. If normal output and alternate
  reentry share one feed or synchronized drain, ordered normal snapshots are
  serialized before final alternate content. Full-history resend may duplicate
  native rows, as accepted. Snapshots are only of the current drain; the caller
  must not reuse stale transitions.
  Each frame resets positioning/pen state after selecting its screen. It emits
  derived text/styles and supported input modes, never raw command output.
  Historical title/bell/clipboard effects and OSC8 metadata are omitted.
  No custom application-key encoder or application-keypad output is included.

Independent assertions
  PASS normal history/screen/cursor: h0/h1 history, styled R, wide U+754C,
    e + U+0301 and final end; source observation remains unchanged.
  PASS alternate attach without normal preload; actual normal exposure,
    one-feed Q output and alternate reentry retain prompt>Q and its cursor.
  PASS explicit and timeout synchronized drains at feed sizes 1/7/65536:
    no normal snapshot before drain; savedQ remains available after reentry.
  PASS 10-to-6-column normal/history reflow and soft-wrap continuity;
    a subsequent repaint clears stale cells and applies cursor/paste/visibility.
  PASS excluded OSC8 hostile C1 metadata never enters derived output;
    ordinary link text remains. Historical bells/OSC actions never replay.

Oracle and limitations
  vt100 0.18.1 is a separate terminal-state implementation, not Alacritty replay
  into itself. Expectations are hand-written. Both depend on vte 0.15.0:
  this is not an independent parser oracle. Native Terminal.app/VS Code
  rendering/scrollback preservation is not exercised in this stage.
  This snapshot serializer is not a fidelity claim for saved pen/DECSC/DECRC,
  arbitrary scroll regions/tabs/charset/origin/pending wrap, cursor style,
  underline colour/extended underline forms, altered palettes or all modes.
  Those are explicit unproven areas, not approved silent product downgrades.
  Tested style fidelity is red/bold and default resets; the serializer's broader
  basic SGR/indexed/RGB emission is not exhaustively oracle-qualified here.
  Live title/bell forwarding is not implemented by this serializer; prior model
  event assertions retain their separate scope.
  No native scheduling/atomic presentation, transport backpressure, catch-up
  races, cross-version behavior or maximum-resource bound is claimed.
  View copies rows/history and output is materialized: production cost remains
  unqualified; no extra authoritative model is introduced.
