ENCODING AND GROUPING
====================
Only U+007F and U+0080..U+009F URI code points are transformed: each of their
UTF-8 bytes becomes uppercase %HH (U+009C -> %C2%9C, DEL -> %7F).
Non-control UTF-8, semicolons and existing percent escapes remain byte-identical.
This is mechanical encoding, not validation, filtering or omission.

ASCII tokens are deterministic and collision-free:
  climon2_<hex original id>_<hex original URI>
The separator is outside the hex alphabet. Including the ORIGINAL URI keeps
groups distinct when URI encoding aliases a literal "%C2%9C" URI. Tokens are
stable across independent derived outputs, not per-writer counters. An initial
counter implementation failed the cross-output grouping test and was removed.
There is no persistent map, hash collision risk, or raw metadata in the token.
This expands id wire length; size/retention policy remains with #48.

Corpus: prior C0, ST, BEL, CAN, invalid UTF-8 URI/id/segment, nested and
unterminated strings; hostile DEL/all 32 C1 code points; the screen-erasing
case; benign percent-escaped and non-ASCII URIs; prior 1 MiB retained URI.
xterm.js checks cells and actual link-service data, not just generated bytes.
vt100 independently checks visible cells after the malformed/hostile cases;
it shares vte with Alacritty, so xterm is the independent parser oracle.
Rust also checks token stability across outputs and encoded-URI alias groups.

RESOURCE AND SOURCE-STATE LIMITS
===============================
Region/charset probes snapshot one cursor and (charset) one cell, and restore
them before return. Tab observation has no getter: widening temporarily is
needed for an exact final-column stop. It snapshots one normal grid INCLUDING
retained history plus one alternate grid, temporarily resizes both through
the engine, and reinstates snapshots. Peak clone descriptors are roughly
24 * columns * (history + 2*screen_lines) bytes, plus row/storage overhead;
Arc-held zero-width/link payloads are shared. Temporary resize/reflow allocations
and the full output also cost memory/time; this is NOT a measured budget pass.
Snapshots are discarded, never updated as a second terminal model.

This differs materially from f113bb6's alternate-only clone cost. Acceptance
of the full-history snapshot is a NEW resource/design decision, not assumed.
An upstream tab-stop accessor avoids this probe and its history copy.
Normal/history output restoration is still mandatory, not application redraw.
The baseline accepted E1 source perturbation still passes its exact regression.
Live repaint does NOT use the resizing/tab probe and does not expand E1 to
live rendering; a failing regression caught and prevented that expansion.

No native Terminal.app, production daemon/client, transport, native latency or
release resource qualification was performed. Whole-engine semantic parity
is not claimed. No unsafe title output is authorised by this experiment.
