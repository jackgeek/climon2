Source-seam review
  Pinned upstream alacritty_terminal/src/term/mod.rs:334-366 provides public
  Config history, Kitty and OSC52 options. Default history is 10000; Kitty is
  false. OSC52 defaults to OnlyCopy, not Disabled. The accepted forwarding test
  deliberately retains upstream event behavior and is not a host emitter.
  Unsupported clipboard events must not be treated as product approval.
  Term::new at lines 410-444 allocates authoritative active and inactive grids;
  inactive history starts at zero. There is no PTY launch in this constructor.

  The wrapper at probe/src/lib.rs forwards Handler operations mechanically and
  snapshots normal state at actual transitions, rather than final-feed mode.
  Its View clones cells/history for inspection; that clone's production cost
  remains unqualified. The tests in probe/tests/transitions.rs and reflow.rs
  use independent expected text/cursor/history, not only same-engine replay.
  probe/src/timing.rs retains the first deadline and requires the caller to
  service it. Tests do not prove a future daemon event loop meets that deadline.

  Upstream alacritty_terminal/Cargo.toml and src/lib.rs:7-16 also include public
  PTY/event-loop modules and Unix/Windows dependencies. Turning default features
  off does not make the upstream dependency graph platform-free. The intended
  climon2-vt boundary must still keep daemon I/O outside its API; no upstream
  patch or new production crate was introduced. The inventory is the prototype's
  resolution, not a decided production dependency footprint or cross-platform
  build qualification.
