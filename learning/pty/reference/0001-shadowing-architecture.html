Where shadowing lives

A PTY gives one host process a terminal-shaped byte channel. Shadowing is the host's policy for copying that channel to additional clients.

ShadowingNot supplied by the PTY API. Your host copies output, arbitrates input, tracks size, and owns lifecycle.

Minimal invariants

  1. Exactly one session object owns the platform PTY or pseudoconsole handles.
  2. Every output byte is read once from the platform boundary, then distributed.
  3. Read-only shadows never write into the child input channel.
  4. Interactive input has an explicit owner or arbitration rule.
  5. A slow shadow cannot indefinitely block the shell or every other viewer.
